# DUK CELL — Deploy independente do Manus

O projeto foi preparado para hospedagem independente.

## Antes de publicar
1. Substitua `https://SEU-DOMINIO-AQUI.com` pelo domínio definitivo da DUK CELL em:
   - `client/index.html` (se aplicável)
   - `client/public/robots.txt`
   - `client/public/sitemap.xml`
   - demais metadados/canonical encontrados no projeto.
2. Rode o build do projeto e confira se todas as imagens em `/assets/` carregam.
3. Publique no Netlify ou GitHub Pages.
4. Cadastre o domínio definitivo no Google Search Console e envie o sitemap.

As imagens devem permanecer em `client/public/assets/`.
